# 사내 RAG 챗봇 개발 작업 목록

## 1단계: 핵심 기능 개발 (2주)

### 서버 (백엔드)

- [ ] **데이터베이스 설정**:
  - [ ] PostgreSQL 서버 설치 및 설정
  - [ ] PGVector 확장 활성화
  - [ ] 지식 문서를 저장할 테이블 스키마 설계
- [ ] **데이터 임베딩 및 저장 파이프라인 구축**:
  - [ ] Python 스크립트 환경 설정 (`requirements.txt` 생성)
  - [ ] 내부 문서(txt, md, pdf 등)를 로드하고 청크로 분할하는 기능 구현
  - [ ] Ollama를 통해 로컬 임베딩 모델(예: `nomic-embed-text`)을 사용하여 텍스트 청크를 벡터로 변환하는 기능 구현
  - [ ] 변환된 벡터와 원본 텍스트를 PGVector에 저장하는 스크립트 작성
- [ ] **벡터 검색 API 서버 구축 (FastAPI 사용)**:
  - [ ] 사용자 질문을 받아 PGVector에서 유사도 높은 문서를 검색하는 API 엔드포인트 (`/search`) 구현
  - [ ] 검색된 문서를 JSON 형식으로 반환하는 로직 작성

### 클라이언트 (윈도우 애플리케이션)

- [x] **GUI 애플리케이션 기본 구조 설계 (Python - Tkinter)**:
  - [x] 메인 윈도우 생성
  - [x] 대화 내용이 표시될 텍스트 영역 구현
  - [x] 사용자 질문을 입력할 텍스트 입력 필드 및 전송 버튼 구현
- [ ] **RAG 흐름 구현 (LangGraph, Ollama)**:
  - [ ] LangGraph를 사용하여 전체 RAG 흐름(Graph) 정의
    - 1. **질문 수신**: UI에서 사용자 질문 받기
    - 2. **문서 검색**: FastAPI로 구현된 벡터 검색 API 서버에 질문을 전송하고 관련 문서(Context) 수신
    - 3. **프롬프트 생성**: 수신된 문서와 원본 질문을 조합하여 LLM에 전달할 프롬프트 생성
    - 4. **답변 생성**: 로컬 Ollama(예: `gemma:2b`)를 호출하여 최종 답변 생성
    - 5. **답변 출력**: 생성된 답변을 UI에 표시
- [ ] **핵심 기능 구현**:
  - [ ] 답변 생성 중 '처리 중...'과 같은 시각적 피드백 UI에 표시 (US-001)
  - [ ] 서버 연결 실패 등 네트워크 오류 발생 시 사용자에게 알림 메시지 표시 (US-001)
  - [ ] 답변 텍스트 복사 기능 구현 (버튼 또는 우클릭 메뉴) (US-002)
  - [ ] 현재 대화 내용을 지우는 '새 대화' 기능 구현 (US-003)

## 2단계: 안정화 및 배포 준비 (2주)

### 클라이언트 (윈도우 애플리케이션)

- [ ] **성능 최적화**:

  - [ ] 애플리케이션 메모리 사용량 최적화
- [ ] **설정 기능 구현**:
  - [ ] 벡터 검색 서버의 주소(IP, 포트)를 저장할 설정 파일(`config.json` 등) 구현
  - [ ] 관리자가 서버 주소를 변경할 수 있는 간단한 설정 UI 화면 구현 (US-005)

  - [ ] 중앙 서버에 최신 버전 정보를 저장할 파일(예: `version.json`) 위치 지정

  - [ ] 새 버전이 있을 경우, 사용자에게 알리고 다운로드 링크 연결
- [ ] **패키징 및 배포 준비**:
