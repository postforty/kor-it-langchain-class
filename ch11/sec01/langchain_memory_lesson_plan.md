# 🧠 LangChain 에이전트 메모리(Memory) 완벽 가이드

안녕하세요! 이번 시간에는 LangChain을 사용하여 똑똑한 AI 에이전트를 만들기 위한 핵심 개념, **기억(Memory)**에 대해 학습합니다.

인공지능(LLM)은 기본적으로 우리가 이전에 했던 말을 기억하지 못합니다. 따라서 우리가 직접 AI에게 기억력을 부여해야 합니다. 이 가이드를 통해 가장 기초적인 메모리 주입 방식부터, 스스로 기억을 관리하는 자율적인 에이전트까지 3단계에 걸쳐 직접 구현해 보겠습니다.

---

## 1. 개요: 단기 메모리와 장기 메모리의 차이

본격적인 실습에 앞서, 에이전트가 사용하는 두 가지 종류의 메모리를 명확히 구분해 봅시다.

> [!NOTE]
> **핵심 비유**: 단기 메모리는 친구와 **'지금 나누고 있는 대화의 흐름'**이고, 장기 메모리는 그 친구의 취향과 특징을 적어둔 **'비밀 노트(프로필)'**입니다.

| 구분 | 단기 메모리 (Short-term Memory) | 장기 메모리 (Long-term Memory) |
| :--- | :--- | :--- |
| **목적** | 현재 진행 중인 **대화 문맥(Context)** 유지 | 여러 대화(세션)에 걸쳐 영구적으로 **지식/정보** 보존 |
| **단위** | 단일 스레드 (`thread_id`) | 스레드 초월 (`user_id` 등 네임스페이스) |
| **구현체** | `Checkpointer` (`InMemorySaver` 등) | `Store` (`InMemoryStore`, `PostgresStore` 등) |
| **특징** | 메시지 히스토리가 너무 길어지면 토큰 한계(Context Window)를 초과할 위험이 있음 | 도구(Tool) 및 벡터 기반 유사도 검색(Semantic Search)을 활용하여 방대한 데이터 관리 |

---

## 2. 실습 가이드: 3단계 메모리 진화 과정

단기 메모리(단순 대화 기록)만으로는 방대한 사용자 정보를 다룰 수 없다는 한계를 극복하기 위해, 다음 3개의 주피터 노트북 예제를 순서대로 실습해 보겠습니다.

### Step 1: 수동 메모리 주입 (Middleware 방식)
*   **실습 파일**: `01_manual_memory_injection.ipynb`
*   **학습 목표**: 메모리 저장소(Store)의 개념을 익히고, LLM에게 텍스트 형태로 과거의 기억을 주입하는 가장 원초적인 방식을 배웁니다.
*   **실습 포인트**: LLM은 스스로 기억할 수 없으므로, 개발자가 과거 기록을 찾아내어 시스템 프롬프트(System Prompt)에 몰래 끼워 넣는 과정을 이해합니다. 미들웨어(`@wrap_model_call`)가 이 역할을 어떻게 수행하는지 코드를 통해 확인해 보세요.

### Step 2: 도구(Tool)를 활용한 자율적 장기 메모리
*   **실습 파일**: `02_agentic_memory_tool.ipynb`
*   **학습 목표**: 개발자가 텍스트를 강제로 주입하는 한계를 넘어, LLM 스스로 도구를 사용해 자율적으로 메모리를 읽고(Read) 쓰는(Write) '에이전틱(Agentic)' 접근법을 배웁니다.
*   **실습 포인트**: 랭체인 공식 문서가 권장하는 **표준 패턴**입니다. `save_user_info` 도구를 챗봇에게 쥐여주면, 대화 도중 "아, 이 사람은 아이스 아메리카노를 좋아하는구나. 저장해둬야지!" 라고 스스로 판단하여 기록하는 과정을 관찰해 보세요.

### Step 3: 시맨틱 검색과 단기/장기 메모리의 결합 (실전 레벨)
*   **실습 파일**: `03_semantic_memory_hybrid.ipynb`
*   **학습 목표**: 수많은 데이터 속에서 정확한 기억을 찾아내는 벡터(Vector) 기반 시맨틱 검색과, 단기 메모리/장기 메모리를 동시에 사용하는 하이브리드 결합 아키텍처를 실습합니다.
*   **실습 포인트**: 
    1. 자연어 질문(`query`)만으로 의미가 유사한 과거 기억을 찾아오는 마법 같은 과정을 확인합니다.
    2. 자연스러운 대화 흐름 유지를 위한 단기 메모리(`checkpointer`)와, 영구적인 정보 보관을 위한 장기 메모리(`store`)가 한 에이전트 내에서 어떻게 동시에 작동하는지 이해하세요.

> [!TIP]
> 각 노트북을 실행해 보며, 여러분이 직접 사용자 입장이 되어 챗봇과 대화해 보세요. 1단계부터 3단계로 갈수록 챗봇이 어떻게 똑똑하게 진화하는지 직접 체감하실 수 있습니다!
